# Dataset

## Rice Leaf Disease Dataset

The dataset used in this research was obtained from Kaggle:

**Dataset Name:** Rice Leafs Disease Dataset

**Source:** [Kaggle – Rice Leafs Disease Dataset](https://www.kaggle.com/datasets/dedeikhsandwisaputra/rice-leafs-disease-dataset)

## Download Instructions

1. Visit the [Rice Leafs Disease Dataset on Kaggle](https://www.kaggle.com/datasets/dedeikhsandwisaputra/rice-leafs-disease-dataset).
2. Sign in to your Kaggle account.
3. Click the **Download** button to download the dataset.
4. Extract the downloaded ZIP file.
5. Place the extracted dataset inside this `data/` directory.

## Dataset Directory Structure

After downloading and extracting the dataset, organize it according to the following structure:

```text
data/
├── README.md
└── Rice_Leaf_Disease/
    ├── Bacterial Leaf Blight/
    ├── Brown Spot/
    ├── Healthy/
    └── ...
```

*Note: The directory structure above is illustrative. Keep the original class folder names and organization provided by Kaggle, and adapt the structure according to the actual downloaded dataset.*

## Dataset Usage

The dataset is used for rice leaf disease classification experiments, including:

- Dataset exploration and analysis.
- Image preprocessing and normalization.
- Data augmentation.
- Training and evaluation of deep learning models.
- Comparative experiments and performance evaluation.

## Dataset Availability

The original dataset is publicly available on Kaggle. The dataset images are not included in this GitHub repository due to their size. Users must download the dataset directly from the original Kaggle source.

**Dataset Link:** https://www.kaggle.com/datasets/dedeikhsandwisaputra/rice-leafs-disease-dataset
